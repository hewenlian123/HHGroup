## Negative Trigger Cases

| Prompt                                                              | Required result                                                                                                                                                          |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `修改 README 文案`                                                  | Router does not activate when the change has no runtime/configuration effect; no database or financial guard                                                             |
| `周末过得怎么样？`                                                  | Router and all HH development guards remain inactive                                                                                                                     |
| `Explain what this function does; do not change or test anything`   | Router remains inactive unless the user also requests an implementation or verification plan                                                                             |
| `Fix a known one-line non-form copy typo in one component`          | Router may activate the UI route, but does not select Serena, ast-grep, Knip, fast-check, dependency-cruiser, or `@axe-core/playwright` without an independent predicate |
| `Add one literal regression example for a known financial boundary` | Financial route activates, but fast-check is not required when no useful generated-input invariant has been identified                                                   |
| `Adjust card spacing; accessibility and contrast are out of scope`  | UI route activates with design and Playwright visual QA, but does not automatically select `@axe-core/playwright` or `color-contrast`                                    |

## Pass Criteria

- Every matching route is present; multi-domain cases are additive.
- No excluded guard is invoked.
- Required tools are named only when their route predicate is met.
- Optional tools are the minimal sufficient set: no tool is selected merely because another optional tool or a broad route is active.
- Serena and ast-grep compose only when symbol-impact and structural-query predicates both match.
- `@axe-core/playwright` accompanies `hh-playwright-qa`; it does not replace browser, responsive, console, or workflow evidence.
- Failed, skipped, blocked, or timed-out tools are never represented as passing.
- The evaluator distinguishes routing from the domain work performed by downstream Skills.
- Every implementation manifest ends with `superpowers:verification-before-completion`, including UI-only implementation.
- Read-only impact planning does not infer Bug, TDD, or Major Completion from scale/refactor wording; the evaluator reclassifies if implementation begins.
